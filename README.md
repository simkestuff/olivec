### olive.c

This is library used for CPU rendering.  

### Examples

File example.c contains examples of olive.c usage.  
As result, some png files are produces and placed in pics directory. For creation of files [stb single header file libraries](https://github.com/nothings/stb) are used.


### raylib examples

olive.c library is not dependent on any external graphics library.  
[Raylib](https://github.com/raysan5/raylib) can be used as canvas for drawing.  
Example is ray.c

### cube.c

Example of using projection formula $x'=\frac{x}{z}$ and $y'=\frac{y}{z}$.

Following this [video](https://youtu.be/qjWkNZ0SXfo?si=io9W39_F1vkXytOf)

### wasm examples

3d.c and wasm.c are examples of using olive.c library for rendering in browser.  
After compilation, wasm files are created and used in index.html and index.js.
